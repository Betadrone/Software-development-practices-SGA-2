GIT COMMANDS USED IN THIS ASSIGNMENT
====================================
Project: software-development-practices-sga-2
Repository: https://github.com/Betadrone/Software-development-practices-SGA-2


STEP 1: LOCAL REPOSITORY SETUP
------------------------------
mkdir software-development-practices-sga-2
    Creates the project folder.

cd software-development-practices-sga-2
    Moves into the project folder.

git config --global user.name "Your Name"
    Sets the name attached to every commit I make.

git config --global user.email "you@example.com"
    Sets the email attached to every commit I make.

git config --global init.defaultBranch main
    Makes "main" the default branch name for new repositories.

git init
    Initializes a new, empty Git repository in the current folder.

git status
    Shows which files are untracked, modified, or staged.


STEP 2: GIT WORKFLOW
--------------------
git add .
    Stages all new and changed files for the next commit.

git commit -m "Initial commit: add index.html and about.html"
    Records the initial state of the project as the first commit.

git add index.html
    Stages the modified index.html file.

git commit -m "Update homepage with intro paragraph"
    Records the modification to index.html as the second commit.

git branch feature
    Creates a new branch named "feature".

git checkout feature
    Switches to the "feature" branch.

git branch
    Lists all local branches; the current branch is marked with an asterisk.
    Used to confirm which branch I am on.

git add about.html
    Stages the file I changed on the feature branch.

git commit -m "Add feature content to about page"
    Commits the change to the feature branch.

git checkout main
    Switches back to the main branch.

git merge feature
    Merges the feature branch into main.

git log --oneline --graph --all --decorate
    Shows the commit history as a compact graph of all branches, with
    branch labels, so all changes and branch activity are visible.


STEP 3: .gitignore
------------------
mkdir temp
    Creates a "temp" folder used to test the ignore rule.

echo "temp data" > temp/test.txt
    Creates a test file inside temp/.

echo "some log" > debug.log
    Creates a test .log file.

.gitignore file contents:
    *.log   -> ignores all files ending in .log
    temp/   -> ignores the entire temp folder

git status
    Confirms .gitignore shows as untracked while debug.log and temp/ do not,
    which proves the ignore rules work.

git add .gitignore
    Stages the .gitignore file.

git commit -m "Add .gitignore for log files and temp folder"
    Commits the .gitignore file.


STEP 4: UNDO OPERATION
----------------------
git add index.html
    Stages the extra change made for the undo demonstration.

git commit -m "Add temporary change (to be undone)"
    Makes the additional commit that will be undone.

git revert HEAD --no-edit
    Undoes the last commit by creating a new commit that reverses it, keeping
    history intact. "--no-edit" accepts the default commit message.

git log --oneline
    Shows the commit list, including the new revert commit.

git status
    Shows the repository state after the undo (working tree clean).


STEP 5: GITHUB INTEGRATION
--------------------------
git remote add origin https://github.com/Betadrone/Software-development-practices-SGA-2.git
    Connects the local repository to the public GitHub repository, named "origin".

git remote -v
    Lists the configured remotes and their URLs to verify the connection.

git push -u origin main
    Pushes the main branch to GitHub and sets it as the default upstream.

git push origin feature
    Pushes the feature branch to GitHub so the branch is visible there.


STEP 6: DOCUMENTATION
---------------------
git add git_commands.txt
    Stages this documentation file.

git commit -m "Add git_commands.txt documenting all commands used"
    Commits the documentation file.

git push
    Pushes the new commit to GitHub.
